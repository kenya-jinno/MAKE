補助的参照推定量である TwoNN ID の位置づけの問題と、Conv-VAE・自然画像における一般性の弱さを解決するための実験プラン

=========
大きく分けると、**「TwoNN ID を主役から補助役へ明確に下げ、その代わりに“補助役としてどこまで信じてよいか”を実験で示す」**ことと、**「Conv-VAE・自然画像では、今は未到達な AU 飽和領域まで実験を拡張して、フレームワーク全体が動く条件を実証する」**ことの2本立てになります。現稿でも、Stage 1 の (\hat d_{ID}) は等長性バイアスを含む補助的参照推定量であり、主要な読み取りは Stage 2 の AU Dynamics に委ねる、という整理はすでに入っています。また、CIFAR-10 では TwoNN の外部妥当性は示せている一方、自然画像や Conv-VAE では AU 飽和プラトーや mknee の安定同定には至っていないと自ら認めています。したがって、次の改稿ではこの2点を“記述上の注意”で終わらせず、**追加実験で埋める**必要があります。

まず **TwoNN ID の位置づけ問題**を解決するには、Three-step で進めるのがよいです。
第一に、本文上の用語をさらに厳密にします。表2では TwoNN ID を「頑健指標」としつつ脚注で「等長性バイアスを含む補助的参照推定量」と書いていますが、ここはやや誤読を招きます。**「数値的には安定だが、幾何学的には biased な補助的参照推定量」**のように、安定性と正確性を分けて書く方がよいです。少なくとも、AU 値と同列の “主要指標” には見えないよう、本文・表・結論で用語を統一した方が通りやすくなります。

第二に、**Stage 1 の妥当性を直接検証する比較実験**を入れるべきです。いまは参照 AE の潜在空間が (\kappa \approx 10^9) と強く非等長であり、そこを通した TwoNN ID は過小・過大評価の両方を起こしうる、と本文自身が述べています。したがって、同じデータに対して
「入力空間での TwoNN / 参照 AE 潜在での TwoNN / IsometricAE 潜在での TwoNN / 必要なら MLE や DANCo」
を並べ、**等長性が改善されると ID 推定がどう動くか**を実証するのが有効です。特に実データ側で IsometricAE あるいは等長性を意識したモデルを導入し、(\kappa)、近傍保存率、Trustworthiness などと TwoNN ID の関係を示せれば、TwoNN を「単なる便利な数値」から「条件付きで信頼できる reference estimator」へ一段引き上げられます。

第三に、**TwoNN ID が壊れる条件も明示的に示す**と強いです。現稿では、Conv-VAE の AU 未飽和時に TwoNN ID が FC-VAE より膨張することを限界として挙げています。これはむしろ重要な結果で、
「AU が十分飽和していないと、TwoNN ID は inflated になりやすい」
という**使用条件**として前面に出せます。つまり、TwoNN を “何にでも使える ID 指標” としてではなく、**AU による収束診断を前提にした補助量**として定式化するわけです。これが明確になると、補助的参照推定量という位置づけに一貫性が出ます。

次に、**Conv-VAE・自然画像における一般性の弱さ**を解決するには、要するに **「まだフレームワークが動いていない領域まで、実験条件を押し広げる」** ことが必要です。現稿では、Conv-VAE では 300 エポックでも m≤32 で AU=m、m=64 でも AU は 54.3 程度で、自然画像でも今回のグリッド範囲では AU 飽和プラトーが未到達です。したがって、今の結果は「一般性が弱い」のではなく、**まだ必要な探索範囲まで到達していない**という状態です。

そのための最優先は、**m の探索範囲を拡張すること**です。本文自身も Conv-VAE では AU 飽和観測に m>64 が必要だと示唆しています。Conv-VAE と自然画像については、少なくとも
m = 64, 96, 128, 192, 256
くらいまで広げ、AU(m) が本当にどこかで曲がるのか、あるいは単調に増え続けるのかを確認すべきです。今のままでは「knee がない」のか「まだ見えていない」のかが判別できません。Neural Networks の査読では、この違いは大きいです。

次に必要なのは、**Conv-VAE と自然画像専用の学習条件最適化**です。現稿でも KL サイクリックアニーリングや固定 (\tau_{knee}) の限界、SVHN で部分的崩壊は見えるのに knee が拾えないことが今後の課題として挙がっています。したがって、FC-VAE と同じ (\beta)、同じエポック数、同じ判定法をそのまま使うのではなく、
(\beta) sweep、annealing schedule、学習 epoch、decoder capacity、(\tau_{knee}) の適応化、二階差分ベースの knee 検出
を、Conv-VAE・自然画像専用に再設計した方がよいです。特に SVHN のように AU が少しだけ m を下回る場合は、固定閾値法より**曲率ベースの検出**の方が合う可能性があります。 

さらに、**自然画像では “TwoNN の妥当性確認” と “フレームワーク全体の一般性確認” を分けて実験する**のが重要です。現状の CIFAR-10 結果は前者としては十分有意義です。しかし後者を示すには、AU/mknee まで含めて
「どの条件なら自然画像でもフレームワークが動くか」
を示さなければなりません。たとえば、データセットを CIFAR-10/SVHN のままにしても、まずは浅い自然画像から始めて m 範囲と学習条件を十分に取り、そこで AU プラトーや knee が見えるかを確認する。そこまで行けば、“自然画像では TwoNN だけ” という現状から一歩進めます。

論文として一番効くのは、最終的に次のような**整理図**を出すことです。
「FC-VAE on MNIST/Fashion-MNIST：フレームワーク完全適用」
「Conv-VAE on MNIST：AU 監視までは有効、knee/飽和は m 拡張が必要」
「自然画像：TwoNN 外部妥当性は確認、AU/mknee は今後の探索領域」
という3段階の表を作ると、一般性の弱さが“欠点”ではなく、**どこまで確かめ、どこから未解決かを切り分けた研究**に変わります。現稿はすでにその方向に近いので、あとは実験を一段追加して、この整理をデータで支えるのがよいです。

優先順位をつけると、
**最優先**は「実データで IsometricAE ないし幾何保存モデルを使った Stage 1 妥当性比較」と「Conv-VAE / 自然画像での m>64 の拡張実験」です。
**次点**は「(\tau_{knee}) の適応化と二階差分法の導入」です。
この3つが入ると、査読で残っている2つの弱点はかなり薄まるはずです。
