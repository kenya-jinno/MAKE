【B】誤り（相互参照・記載の機械的誤り）
----------------------------------------------------------------
B-1. 「付録付録E」等の重複表記（8箇所以上）
     jsarticle では \appendix 後の \ref{app:...} が既に「付録E」を返す
     ため、「付録\ref{app:...}」と書くと「付録付録E」になる。
     該当行（NN31.tex）: 882, 893, 895, 1136, 1141, 1442, 1444, 1752,
     1789, 1800, 1802, 2143, 2182 のうち「付録\ref」の形の全箇所。
     → 対処: 直前の「付録」の文字を削除（\ref のみとする）。

B-2. 表1（記号表, p.5）の自己参照的表記
     「$m^{cand}$（= $m^{cand}$）」「$m^{sat}$（= $m^{sat}$）」
     「$m^{knee}$（= $m^{knee}$）」——マクロ \dzopt 等の定義が現行では
     m^{cand} 等と同一のため、括弧内が無意味な自己反復になっている。
     → 対処: 括弧書き（= …）を削除。

B-3. 密グリッドの隣接点間隔の記載誤り（§5.3.7, p.18 および 表13, p.19）
     グリッド m = {8..16(1刻み),18,20,24,28,32,40,48,64}（17点）の
     隣接間隔は 1〜16（48→64 の間隔が 16）であるのに、本文は
     「隣接点間隔 1〜8」、表13 は「Max. grid interval 8」と記載。
     命題2の上界（max 間隔）の議論に関わるため正確を期すべき。
     → 対処: 本文「隣接点間隔 1〜16（推定 ID 近傍の 8〜16 は 1 刻み）」、
       表13「16 (step 1 for 8–16)」に修正。

B-4. 二階差分法の式参照誤り（付録C, p.41）
     「二階差分代替手法（式(21)）の使用を推奨する」とあるが、式(21)
     （\label{eq:knee_curvature}）は指数飽和モデル ρ(m)≈exp(−λ(m−d_ID))
     であり二階差分法の式ではない。
     → 対処: 式参照を削除し「二階差分代替手法（§6.2 の安定化戦略 5）」
       等の記述参照に変更。

B-5. 「表参照」のみで表番号が無い（§5.6, p.24, 行1444）
     「（付録F, 表参照）」→ 表30（\label{tab:en_ext}）への明示参照に修正。

B-6. §5.10 のモデル説明と表23の κ 値の不整合（p.28–29）
     「通常 AE（κ ≈ 10²〜10³）」と記載されているが、表23 では AE の κ は
     m=10 で 85（10²未満）〜 m=100 で 4.1×10⁷ に及ぶ。
     → 対処: 「κ ≈ 10²〜10⁷（m に依存して増大）」等に修正。

B-7. 全角コロンの不自然な挿入（§5.3.5, p.18, 行1127）
     「Exp-Mnist-Multi-150（：m^knee = 32〜64）」→「（m^knee = 32〜64）」。

B-8. 「AU/mknee フレームワーク」の数式モード欠落（§5.7, p.24, 行1493）
     mknee が平文のまま。→ 「AU/$m^{knee}$ 診断フレームワーク」に修正。

【C】不明瞭・わかりにくい点（意味は通るが改善すべき）
----------------------------------------------------------------
C-1. 式(21)の減衰定数 λ と データ固有値 λ_j の記号衝突（付録C）
     定理1で λ_j はデータ共分散固有値。式(21)の指数減衰率にも λ を
     使っており紛らわしい。→ 減衰率を γ に改名。

C-2. 図2（Exp-Stab）と表28（Exp-Iso-ID）の Swiss Roll TwoNN 値の乖離
     が説明不足: 図2 では AE(m=2)=1.55、表28 では AE(m=2)=1.780。
     実験設定（データ生成・n・スケーリング）が異なるためだが、読者が
     同一条件と誤解しうる。→ §5.2.4 に「Exp-Stab と Exp-Iso-ID は独立
     の学習走行であり絶対値は直接比較できない」旨の注記を追加
     （付録Cの表26 注記と同様の書き方）。

C-3. 表9（p.15）の「ρ(m) の変化」列の記述「低」「緩やか」が簡素すぎ、
     かつ英語キャプションの表内に日本語セルが混在。
     → セルを「normal increase / sharp drop (m^knee=12) / low /
       gradual」等の英語に統一（他の表と整合）。

C-4. 実験名の略称が説明なしで使われる箇所がある（ユーザー指示:
     「実験は略語を極力使用せず実験内容がわかるように」）。
     多くの箇所は「実験 Exp-…（内容説明）」形式だが、以下は裸の略称:
     - §5.2.4 冒頭「Exp-Stab（Swiss Roll）では…」
     - §6.1〜6.7 の Exp-… 群（Exp-Real-Geom, Exp-NatImg-Sweep 等）
     - §7 むすび の Exp-… 群
     → 対処: 各節での初出時に括弧または読点で実験内容の短い説明
       （例: 「Exp-Stab（Swiss Roll での κ と TwoNN 安定性の補助実験）」）
       を付す。全箇所での反復は冗長になるため、節単位の初出に付す方針。

C-5. 表4（p.12）「0.0005 ± 0.0000」の表記
     std が丸めで 0 に見える。→ 「± 0.00003」等の有効桁を示すか
     「±0.0000（<10⁻⁴）」と注記。（元データ確認の上で修正）

C-6. 表13 の「seed=[11,9,11]」という角括弧表記（p.19 本文側）
     文中では「（シード別: 11, 9, 11）」の方が読みやすい。
